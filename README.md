# Werewolf_Game
Bu kod, ağ üzerinden çok oyunculu Vampir-Köylü oyununu yöneten bir sunucu yazılımıdır. socket ve threading kütüphanelerini kullanarak oyuncuları aynı lobide toplar, onlara gizli roller atar ve oyunu Gece (avlanma) ile Gün (tartışma/oylama) döngüleri arasında otomatik olarak ilerletir.
